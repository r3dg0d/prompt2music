# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-10-19

### Added

- Standalone release of the prompt2music subsystem from ai-media-cli: the
  `prompt2music` / `aimusic` CLI and the `prompt2music-mcp` / `aimusic-mcp`
  MCP servers.
- Model registry (ACE-Step 1.5, Stable Audio 3, MusicGen, HeartMuLa, YuE2,
  Demucs), isolated backend venvs, Hugging Face downloader with verification,
  job daemon, library, FFmpeg toolkit, prompt/lyrics tools, benchmarks,
  Nix package, Home Manager and NixOS modules.
